# Focus Guard v0.2.0 — учебный режим для Windows

Вместо легко пропускаемых уведомлений: **настоящая блокировка YouTube в Chrome и Edge** на время учёбы.

- Кнопки **25 / 40 / 60 минут** в Windows-приложении.
- Расширение Chromium Manifest V3 перекрывает YouTube, Shorts, `youtu.be`, встроенные видео и YouTube-потоки.
- Уже открытые вкладки YouTube переводятся на экран блокировки.
- Срок сессии сохраняется на диске и в расширении: переключение окон или закрытие программы не снимают уже полученную блокировку.
- После истечения таймера расширение автоматически убирает правила.
- Никаких новых отчётов и внешней передачи истории ActivityWatch. Старые всплывающие напоминания по умолчанию выключены.

## Установка

1. Скачай **`ActivityWatchFocusGuard.exe`** и **`FocusGuardBrowserExtension.zip`** из Assets выпуска.
2. Запусти `.exe` на Windows 10/11.
3. Распакуй ZIP. В Chrome (`chrome://extensions`) либо Edge (`edge://extensions`) включи режим разработчика, нажми «Загрузить распакованное» и укажи папку с `manifest.json`.
4. В `.exe` выбери 25/40/60 минут. В расширении нажми «Проверить сейчас» для немедленной синхронизации.
5. Убедись, что YouTube показывает экран блокировки.

**Важно:** старый `.exe` от v0.1.0 не умеет запускать учебную сессию. Требуются обе новые части. Блокировка действует только в браузерах и профилях, где расширение установлено, и не распространяется на iPhone. При отключении или удалении расширения её можно обойти.

Исполняемый файл не подписан сертификатом издателя. Сверяй SHA-256 с `SHA256SUMS.txt` и запускай только сборку из доверенного источника.
