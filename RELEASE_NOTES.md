# Focus Guard v0.4.0 — локальный веб-интерфейс и системный трей

Полное обновление внешнего вида и способа управления.

- **Нет окна Windows на панели задач**: программа работает из системного трея.
- По запуску и двойному щелчку по иконке в трее открывается **`http://127.0.0.1:8766/`** в обычном браузере.
- Современный тёмный дизайн: крупный таймер, выбор 25/40/60 минут, статус защиты Windows и ActivityWatch.
- Данные и интерфейс локальны, внешних серверов и отчётов нет.
- Сохранена системная блокировка YouTube через `hosts` и независимое запланированное восстановление доступа.
- Административные действия доступны только из локальной страницы, открытой через значок трея, и дополнительно требуют Windows UAC.
- Все веб-файлы упакованы внутрь **одного EXE** — расширения Chrome не требуется.

## Установка

Скачай `ActivityWatchFocusGuard.exe` из Assets, запусти и найди зелёный значок Focus Guard в трее Windows. Откроется страница на localhost. Управляй сессией через браузер; для выхода нажми правой кнопкой по значку трея и выбери «Выход».

**Нужна новая сборка v0.4.0:** прежние EXE не содержат веб-панель. Программа не подписана цифровым сертификатом. Проверь `SHA256SUMS.txt` и убедись, что запускаешь файл из доверенного источника.

Ограничение: блокировка через `hosts` может обходиться уже открытыми соединениями, DNS-кэшем, VPN или прокси. На реальной Windows нужно проверить, что сайты блокируются и доступ восстанавливается по истечении таймера.
