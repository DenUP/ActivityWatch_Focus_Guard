# ActivityWatch Focus Guard v0.1.0 (Windows)

Первая экспериментальная сборка для Windows.

- Один файл `ActivityWatchFocusGuard.exe`; Python отдельно не нужен.
- Локальное чтение ActivityWatch 0.14.x на `127.0.0.1:5600`.
- Автоматическая пауза при длительном открытии YouTube / Shorts, Reels / TikTok, соцсетей и выбранных игровых приложений.
- Кнопки «Вернуться к делу», «Учебное видео», «Перерыв»; задержка перед продолжением.
- Небольшое окно состояния для проверки и корректного завершения.
- Нет отправки данных, отчётов, автоматического запуска вместе с Windows и принудительной блокировки сайтов.

## Установка

1. Установи и запусти ActivityWatch 0.14.1.
2. Скачай `ActivityWatchFocusGuard.exe` из Assets ниже.
3. Запусти файл двойным щелчком. Для проверки нажми «Проверить окно».
4. Необязательные настройки доступны через `config.json` рядом с `.exe` (пример в репозитории).

**Важно:** исполняемый файл не подписан цифровой подписью издателя. Это ранняя версия; см. исходный код и файл `SHA256SUMS.txt` для проверки целостности. Windows-сборка выполняется автоматически на GitHub Actions.
