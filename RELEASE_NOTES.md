# Focus Guard v0.3.0 — один EXE, без расширения браузера

Главное изменение: системная блокировка основных адресов YouTube в Windows на 25, 40 или 60 минут. Расширение Chrome/Edge больше не нужно.

- Один `ActivityWatchFocusGuard.exe` для Windows 10/11.
- Программа запрашивает UAC **при включении** блокировки.
- Перед изменением `hosts` создаёт независимое задание Планировщика Windows `ActivityWatchFocusGuard-Unblock` с восстановлением после установленного времени.
- Задание содержит собственный код восстановления и не зависит от существования EXE.
- Системное ограничение не сбрасывается при переключении окон, сворачивании или закрытии приложения.
- Аварийное восстановление доступно явно, через повторное подтверждение и права администратора.
- Сохраняются исходные строки `hosts`, кроме собственного помеченного блока. Без новых отчётов и передачи данных ActivityWatch.

## Использование

1. Скачай один EXE из Assets.
2. Запусти, нажми «Начать 25/40/60 мин» и подтверди запрос Windows.
3. Если YouTube был уже открыт, перезапусти вкладку или браузер для проверки.
4. Установленная блокировка должна исчезнуть по окончании срока. Если этого не произошло, нажми «Аварийно восстановить доступ»; подробная ручная инструкция есть в README.

Старый EXE и расширение v0.2 не подходят для нового режима; прежнее расширение можно удалить. Блокировка через `hosts` **не абсолютна**: VPN, прокси, кэш соединений и некоторые другие адреса YouTube могут обходить её. Установка системных ограничений протестирована модульно, но нуждается в проверке на реальной Windows.

Программа не подписана цифровым сертификатом. Сверяй файл с `SHA256SUMS.txt` и используй только доверенный исходный код.
