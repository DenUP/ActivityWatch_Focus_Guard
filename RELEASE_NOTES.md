# Focus Guard v0.5.0 — первый шаг и непрерывная концентрация

Версия для работы с отвлечениями, а не для дополнительного учёта активности.

- **Первый конкретный шаг**: перед включением блокировки запиши действие, которое начнёшь прямо сейчас. Текст отображается во время сессии и хранится только в оперативной памяти приложения.
- **25 / 50 / 75 минут**, по умолчанию 50. Никаких принудительных перерывов или дополнительных отчётов.
- **Продление без разблокировки**: +25 или +50 минут (с ограничением срока в пределах трёх часов). Сначала обновляется независимое задание восстановления Windows, потом — таймер.
- Напоминание убрать телефон: системная блокировка Windows не действует на мобильные устройства.
- Локальная веб-панель **`http://127.0.0.1:8766/`** и значок в трее, без отдельного окна Windows и расширений браузера.
- Сохранены UAC, системная блокировка YouTube через `hosts`, автоматическое восстановление и аварийный выход.

## Установка

Скачай **новый** `ActivityWatchFocusGuard.exe` версии v0.5.0 из Assets, запусти и найди зелёный значок Focus Guard в трее Windows. Откроется страница на localhost. Управляй сессией через браузер; для выхода нажми правой кнопкой по значку трея и выбери «Выход».

**Нужна новая сборка v0.5.0:** прежние EXE не содержат новые возможности. Программа не подписана цифровым сертификатом. Проверь `SHA256SUMS.txt` и убедись, что запускаешь файл из доверенного источника.

Ограничение: блокировка через `hosts` может обходиться уже открытыми соединениями, DNS-кэшем, VPN или прокси. Она не блокирует iPhone/Android. На реальной Windows проверь, что сайты блокируются и доступ восстанавливается по истечении **продлённого** таймера.
