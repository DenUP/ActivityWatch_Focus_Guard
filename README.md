# Focus Guard for Windows + ActivityWatch 0.14.1

## Скачать готовую программу (.exe)

Когда выпуск появится, перейди на страницу [Releases](https://github.com/DenUP/ActivityWatch_Focus_Guard/releases) и скачай `ActivityWatchFocusGuard.exe` из последнего выпуска. **Пользователю Python устанавливать не нужно**. ActivityWatch 0.14.1 должен быть запущен.

Дважды щёлкни скачанный `.exe`. Откроется небольшое окно состояния. Для пробного вмешательства нажми «Проверить окно». **Крестик, кнопка «В трей» и обычное сворачивание убирают окно с панели задач, оставляя значок рядом с часами Windows.** Чтобы снова открыть окно, дважды щёлкни значок или выбери «Открыть» в его меню. Для полного выхода выбери «Завершить» в меню трея или в основном окне. Пока программа находится в трее, она продолжает реагировать на отвлечения. Старт вместе с Windows автоматически не включается.

Рядом с `.exe` можно положить необязательный `config.json` (см. пример в репозитории). Без него используются встроенные настройки. Программа не требует администратора.

**Важно:** программа пока не подписана цифровой подписью издателя. Windows может показать предупреждение SmartScreen. Не отключай защиту ради запуска: проверяй источник и контрольную сумму выпуска. В таком случае также можно запустить исходный код (инструкция ниже).

### Как собрать и опубликовать EXE (для владельца репозитория)

В репозитории подготовлен GitHub Actions workflow `.github/workflows/release-windows.yml`. Однако GitHub может отключить Actions для конкретного репозитория. В этом случае выпуски **не создаются автоматически**.

Ручной способ на Windows:

1. Установи Python 3.11+ (рекомендуется Python 3.12) и скачай исходники через **Code → Download ZIP**.
2. Распакуй ZIP и запусти `build_windows.bat` двойным щелчком. Скрипт запустит тесты, установит PyInstaller и соберёт один `.exe`.
3. В папке `dist` появятся `ActivityWatchFocusGuard.exe` и `SHA256SUMS.txt`.
4. Открой [Releases](https://github.com/DenUP/ActivityWatch_Focus_Guard/releases), выбери **Draft a new release** и создай тег `v0.1.0` на ветке `master`.
5. Загрузи в **Assets** оба файла из `dist`, добавь описание из `RELEASE_NOTES.md` и нажми **Publish release**.

Так Python требуется только человеку, который собирает выпуск. Остальные скачивают готовый `.exe`.

## Запуск из исходного кода

Локальная программа для **изменения поведения в момент отвлечения**. Не строит отчёты, не загружает историю в облако и не изменяет ActivityWatch. Читает API только на `127.0.0.1:5600`.

## Что происходит

- Если YouTube находится на переднем плане примерно **3 минуты подряд**, появляется окно-пауза.
- Если ActivityWatch видит URL YouTube Shorts, пауза появляется через **40 секунд**. Для Reels / TikTok — через 45 секунд; для соцсетей — через 3 минуты; для игр из списка — через 5 минут.
- В окне можно **свернуть отвлекающую программу**, разрешить **10 минут отдыха** или **30 минут учебного видео**.
- Перед разрешением продолжать действует **15-секундная задержка**. Выбор «Вернуться к делу» доступен сразу.
- Если нажать `Esc` или закрыть окно, оно исчезнет минимум на 90 секунд. Программа намеренно не запирает компьютер.
- Когда ты отошёл от компьютера (AFK), время отвлечения не накапливается.

## Установка на Windows

1. Убедись, что запущен ActivityWatch 0.14.1. Открой в браузере `http://localhost:5600`.
2. Установи **Python 3.11+** с [python.org](https://www.python.org/downloads/windows/). При установке включи добавление Python в PATH.
3. Распакуй архив и открой PowerShell в папке проекта.
4. Для проверки выполни: `py -3 -m unittest -v`.
5. Сначала можно посмотреть, как выглядит вмешательство, не подключаясь к ActivityWatch: `py -3 focus_guard.py --demo`.
6. Для запуска: дважды щёлкни `start_windows.bat` или выполни `py -3 focus_guard.py`. Оставь терминал открытым.
7. Для завершения закрой окно терминала или останови процесс через `Ctrl+C` (когда терминал в фокусе).

Для запуска из исходников с системным треем установи зависимости: `py -3 -m pip install "pystray==0.19.5" "Pillow>=10,<13"`. В готовом EXE эти зависимости уже включены.

### Для точного определения YouTube Shorts

Полезно установить официальный **aw-watcher-web** для своего браузера — он передаёт активный URL в ActivityWatch. Без него программа использует URL, если его предоставляет оконный watcher, или осторожный запасной вариант по заголовку окна. В последнем случае Shorts и обычный YouTube не различаются, поэтому действует 3-минутное правило.

Проверь в `http://localhost:5600/#/buckets`, что доступны bucket'ы `aw-watcher-window_...`, `aw-watcher-afk_...`, а для точного определения вкладок — `aw-watcher-web-...`.

## Настройки

В `config.json` можно изменить пороги в секундах, период отдыха, задержку выбора и период учебного видео. Например, `"youtube": { "seconds": 120 }` — окно после двух минут непрерывного просмотра.

Если какое-то приложение не нужно отслеживать, удали его из `game_apps` при добавлении полного списка к конфигурации. Все значения по умолчанию перечислены в `focus_guard.py`.

## Как это внедрять

**Первые 3 дня** — пусть автоматически появляется только окно-пауза. Оцени субъективно: помогает ли оно возвращаться к делу или ты просто нажимаешь «Перерыв»? Отдельного отчёта не требуется. Если окно помогает, включи запуск при входе в Windows через обычный ярлык в папке автозагрузки (`Win+R` → `shell:startup`), ведущий к запуску скрипта.

Если окно не помогает, лучше добавить *настоящую блокировку через расширение браузера*, например [LeechBlock NG](https://www.proginosko.com/leechblock/), чем менять системный `hosts`, брандмауэр или убивать процессы. Прямая интеграция автоматической блокировки с ActivityWatch потребует отдельного браузерного компонента.

## Безопасность и ограничения

- **Это мягкое вмешательство, не жёсткий блокировщик.** `Esc` и закрытие окна всегда доступны. Упоминание «свернуть» — обратимое действие, выполняемое только по твоему нажатию.
- Программа не меняет DNS, `hosts`, процессы браузера, фаервол, реестр или настройки ActivityWatch. Администратор не требуется.
- Программа не отправляет данные в интернет и не пишет историю окон / сайтов на диск. При сетевых ошибках повторяет попытку без вмешательства.
- Она не отличает развлекательное видео от учебного автоматически, поэтому выбор остаётся за тобой.
- Несколько браузеров и устройств одновременно, веб-страницы с неоднозначными названиями и длительные видео без клавиатуры могут определяться неидеально. При отсутствии свежих данных действия не выполняются.
- Не запускай программу в учёбе / экзамене, когда неожиданное окно может мешать важной работе, до того как проверишь её на обычном использовании.

## Проверки

`py -3 -m unittest -v` — небольшие тесты на точность доменов, устаревшие события, переключение окон и период молчания после вмешательства.
