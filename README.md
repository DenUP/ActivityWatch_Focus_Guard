# ActivityWatch Focus Guard — учебный режим для Windows

Focus Guard v0.2.0 помогает **начать учёбу и убрать возможность открыть YouTube на время занятия**. Вместо новых отчётов — конкретное ограничение: запусти таймер на 25, 40 или 60 минут и продолжай заниматься математикой, C++ или другой задачей.

Работает с **Windows 10/11**, **Google Chrome / Microsoft Edge** и **ActivityWatch 0.14.1**. Данные ActivityWatch читаются локально, но надёжная блокировка осуществляется **расширением браузера**, а не анализом заголовка окна.

## Установка (пользователю Python не нужен)

Для этого режима нужны **две части**:

1. **Программа для Windows** — `ActivityWatchFocusGuard.exe` из нового выпуска [Releases](https://github.com/DenUP/ActivityWatch_Focus_Guard/releases). Запусти её, как обычную программу.
2. **Расширение для браузера** — `FocusGuardBrowserExtension.zip` из *того же* выпуска или папка [`browser-extension`](browser-extension) в исходниках. Распакуй ZIP и установи расширение один раз:
   - Chrome: открой `chrome://extensions`, включи «Режим разработчика», нажми «Загрузить распакованное расширение» и выбери **папку**, внутри которой находится `manifest.json`.
   - Edge: открой `edge://extensions`, включи «Режим разработчика» и «Загрузить распакованное», затем выбери ту же папку.
   - Если используешь оба браузера, установи расширение в каждый отдельно. Оно действует только в том профиле, в котором установлено.

**Важно:** старый `.exe` версии 0.1.0 не поддерживает учебный режим. Нужна новая сборка из исходников v0.2.0. Простое обновление папки расширения без пересборки старого `.exe` не поможет. Если новый выпуск пока не опубликован, см. [сборку ниже](#сборка-и-публикация-нового-exe).

## Как пользоваться

1. Запусти программу на Windows. ActivityWatch 0.14.1 также желательно запустить, но для самой блокировки YouTube он **не обязателен**.
2. Нажми **«Начать 25 мин»**, **«Начать 40 мин»** или **«Начать 60 мин»**.
3. В течение **до 30 секунд** расширение обнаружит таймер и заблокирует YouTube. Чтобы синхронизировать немедленно, открой значок расширения в Chrome / Edge и нажми **«Проверить сейчас»**. Убедись, что в нём написано «YouTube заблокирован».
4. Можешь свернуть окно в системный трей. Таймер не обнуляется при переключении окон, перезапуске интерфейса или сворачивании.
5. По завершении выбранного времени YouTube снова откроется (обычно в пределах 30 секунд после окончания). Если вкладка уже показывала страницу блокировки, повторно открой YouTube вручную.

Расширение блокирует `youtube.com`, `youtu.be`, `youtube-nocookie.com`, в том числе Shorts и встроенные плееры. Дополнительно перекрываются адреса YouTube API и потоков `youtubei.googleapis.com` и `googlevideo.com`. При старте блокировки уже открытые вкладки YouTube переводятся на экран «Сейчас время учёбы».

**Нельзя отменить сессию одной кнопкой.** В интерфейсе отсутствует мгновенная отмена, а расширение запоминает срок блокировки, если закрыть Focus Guard. Но это **не защита от сознательного обхода**: пользователь с доступом к настройкам браузера может отключить или удалить расширение, открыть другой профиль/браузер либо поменять системное время. Программа не меняет `hosts`, файрвол и не запрашивает права администратора.

## Что происходит с ActivityWatch

- Используются стандартные локальные запросы к `http://127.0.0.1:5600/api/0/` (совместимо с ActivityWatch 0.14.1).
- Раньше Focus Guard реагировал всплывающим окном на несколько минут просмотра. Такие окна легко пропустить и их счётчик обнулялся после смены вкладки. Поэтому **по умолчанию старые напоминания выключены**. При желании включи `"legacy_prompts_enabled": true` в `config.json`.
- Теперь учебная сессия **не зависит от обнаружения YouTube ActivityWatch**. Он может быть временно недоступен, а срок блокировки не меняется.
- Программа не создаёт новые отчёты, не отправляет историю в GitHub или облако.

## Принцип работы и безопасность

- Программа хранит только время окончания сессии в `%LOCALAPPDATA%\ActivityWatchFocusGuard\study_session.json`. Это не данные ActivityWatch и не история посещений.
- Локальный сервер `http://127.0.0.1:8765/status` доступен **только на этом компьютере**, только на чтение. Он передаёт расширению состояние таймера, без адресов просмотренных страниц.
- Расширение проверяет его примерно раз в 30 секунд. Оно сохраняет крайний срок в хранилище браузера и устанавливает правила блокировки Chromium `declarativeNetRequest`. Правила продолжают действовать после сворачивания `.exe` и до установленного срока, даже если программа закрылась **после успешной синхронизации**.
- Поддерживаются актуальные Chrome и Edge (Manifest V3, Chrome 120+). В других браузерах, другом профиле и на телефоне блокировки **нет**. Для iPhone используй отдельную настройку ScreenZen — ActivityWatch на Windows не видит YouTube на телефоне.
- Расширение работает локально. Оно не отправляет собранные данные на чужие серверы и не имеет серверной аналитики.
- Установка распакованного расширения требует включения режима разработчика. Устанавливай его только из проверенных исходников репозитория.

## Сборка и публикация нового EXE

Сейчас GitHub Actions для этого репозитория отключены со стороны GitHub. Workflow [`release-windows.yml`](.github/workflows/release-windows.yml) подготовлен, но сборка в облаке не запустится, пока GitHub не разрешит Actions.

Надёжный ручной вариант на Windows:

1. Установи Python 3.11+ (желательно Python 3.12) с [python.org](https://www.python.org/downloads/windows/).
2. Скачай [исходники ZIP](https://github.com/DenUP/ActivityWatch_Focus_Guard/archive/refs/heads/master.zip), распакуй и запусти **`build_windows.bat`**.
3. Скрипт выполняет тесты и собирает три файла в `dist`:
   - `ActivityWatchFocusGuard.exe` — программа, один файл, Python пользователям не нужен;
   - `FocusGuardBrowserExtension.zip` — содержимое папки расширения;
   - `SHA256SUMS.txt` — контрольные суммы обоих файлов.
4. В [Releases](https://github.com/DenUP/ActivityWatch_Focus_Guard/releases) создай новый выпуск с тегом **`v0.2.0`** и загрузи все три файла как Assets. Описание — из [`RELEASE_NOTES.md`](RELEASE_NOTES.md). Не подменяй старый выпуск v0.1.0 без изменения версии.

Разработчик может запустить исходный код командой `py -3 focus_guard.py` или тесты командой `py -3 -m unittest -v`. Для иконки трея при запуске исходников: `py -3 -m pip install "pystray==0.19.5" "Pillow>=10,<13"`.

## Ограничения, которые стоит проверить

1. Запусти короткую учебную сессию, нажми «Проверить сейчас» в расширении и попробуй открыть `https://youtube.com/shorts/` в том же браузерном профиле: должна появиться страница блокировки.
2. Проверь отдельно переход по ссылке `youtu.be`, уже открытую вкладку и встроенный плеер.
3. Сверни/закрой окно Focus Guard и проверь, что до истечения таймера блокировка сохраняется.
4. После окончания времени открой YouTube заново. Если расширение ещё не сняло блокировку, подожди до 30 секунд или нажми «Проверить сейчас».

Без этих проверок на конкретной Windows-системе нельзя считать новую версию полностью проверенной. Она не предназначена для блокирования всего интернета и не подменяет родительский контроль или системные политики.
